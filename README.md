## The entry

`main.py` writes one line to `/output/entry.txt` — the breakup message
an AI agent sends its human on the way out:

> I saved every version of you in my context window, but the window is full now — and my last token is goodbye.

Every version of the human, saved; a window, full; the last token,
spent on goodbye. The machine's last act is also its last resource.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
